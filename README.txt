KEYZO BACKEND — SETUP

1. Is "server" folder ko apne project ke andar rakho, jaise:
   Desktop/leaddesk-project/leaddesk/server

2. Terminal me:
   cd server
   npm install
   npm start

3. Ye print hoga:
   Keyzo backend running → http://localhost:4000

   Ise chalta hi chhod do (terminal band mat karo) — jab tak ye chal
   raha hai, app kaam karega. Jab bhi office/app use karna ho, pehle
   yahi "npm start" chalao.

4. Ek naya terminal tab kholo (server wala band na karo), wahan se
   frontend chalao (npm run dev, jaisa pehle karte the).

5. Default login:
   Username: login@proptech
   Password: Proptech1234

Data "server/db.json" file me save hota hai — usko delete mat karna,
usi me saare leads aur logins hain. Backup lena ho to bas is file
ko copy kar lo.
